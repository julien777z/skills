# Shared rules

The canonical reusable guidance is in `~/.codex/rules/*.md`, linked from the skills repository. Read `global.md` and `github.md` at the start of repository work, then read only rules relevant to the files and tools in the task (for example `python.md`, `testing.md`, or `react.md`). Read repository `AGENTS.md` and project rules too; they supply repository-specific context. A direct user instruction takes precedence.

Edit reusable rules and skills in the skills repository. Keep repository-specific commands and facts with their owning repository. Do not copy shared rules or skills into consumer repositories.
