# Artifacts publishing

Use the session's HTML artifact publishing tool and its current schema. Render with `--fragment`
when it supplies the document skeleton, the full page otherwise. Publish as a plain HTML page so
the shared dashboard template remains the page the reader sees.

Update the artifact the shared delivery lookup found for this dashboard; create one only when
none exists. Follow the tool's icon, description and size requirements. Inspect its save receipt,
read the saved content when supported, and check the rendered page and its controls when preview
is available. Return its link and identify any rendering or interaction left unverified.
