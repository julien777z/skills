# Widen Scope

Switch on `scope-of-change`'s widened budget for the rest of the session: once the user turns it on,
it holds for every task and follow-up until the user says to stop. That budget's bullet holds what
it covers, how its record is kept and the report line it adds.

## Dependencies
- `scope-of-change`
