# Process Review

What the process review reads and what counts as waste; read from `SKILL.md`'s **Process Review**,
which sets when it runs, the span it covers and where each finding goes.

- **What it reads.** Your own steps and every subagent, review round, gate, council and skill-test
  run in the span, with their findings and how long each was waited on, from the ledger, the run
  records and the reports you hold.
- **What counts as waste**: time or usage spent with no gain in what the work achieved, such as
  fixes that undo or redo each other, a flag rejected and repaired again and again, a gate asking
  for evidence its brief could have carried, rounds past a limit, a launch, gate or loop repeating
  what an earlier step settled, parallel agents given the same task, a full rerun where only a
  small part changed, one diff read by several agents for overlapping criteria, and a wait on an
  agent that had stalled.
- **What is never waste.** A cost that buys effectiveness, such as a round cap, an independent
  gate, a second reviewer or a skill test, is not waste and is never cut to save time or usage.
- With nothing found, the report says so in one line.
